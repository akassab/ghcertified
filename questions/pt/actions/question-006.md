## Correct answer

- [x] Workflows podem executar um ou vários jobs ao mesmo tempo
- [x] Workflows podem ser acionados manualmente, por um evento ou executados em uma programação
- [x] Workflows devem ser definidos no diretório `.github/workflows`
- [ ] Workflows só podem ser executados em uma programação
- [ ] Workflow pode executar apenas um job por vez
- [ ] Workflows são escritos em qualquer formato como `.yaml`, `.json` ou `.toml`
> Workflows só podem ser definidos no formato `.yaml`
- [ ] Workflows podem ser compartilhados no GitHub Marketplace
> Actions (não workflows) podem ser compartilhados no GitHub Marketplace
