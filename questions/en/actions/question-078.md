## Correct answer

- [x] Each workflow is composed of one or more jobs which is composed of one or more steps, and each step is an action or a script
> A workflow YAML defines jobs; each job has steps. A step either runs an action (`uses:`) or shell commands (`run:`). Actions are reusable units invoked by steps—they are not containers that hold entire workflows.
