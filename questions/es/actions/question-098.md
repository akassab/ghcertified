<!-- Unchecked choices are shown first; correct answers are below the spacer. -->

- <input type="checkbox" disabled> agregar una condición en el archivo YAML del flujo de trabajo para los días de semana
- <input type="checkbox" disabled> no es posible en GitHub Actions
- <input type="checkbox" disabled> usar el disparador de evento on: schedule: weekdays
- <input type="checkbox" disabled> usar el disparador de evento on: schedule: cron
